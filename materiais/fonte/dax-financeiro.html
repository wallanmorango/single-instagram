Antes de começar

Três medidas base e uma tabela calendário

Todas as medidas deste material usam estas três. Ajuste os nomes das tabelas e colunas para os do seu modelo.

medidas-base.dax
Receita = SUM ( Vendas[Valor] )
Custo = SUM ( Vendas[Custo] )
Orçado = SUM ( Orcamento[Valor] )
  • Crie a tabela CalendarioCalendario = CALENDARAUTO ()
  • Marque como tabela de datasFerramentas da tabela → Marcar como tabela de datas
  • Relacione com Vendas e OrcamentoCalendario[Data] → Vendas[Data] e Orcamento[Data]

01

Receita YTD

Soma de janeiro até a data selecionada. Zera na virada do ano.

01-receita-ytd.dax
Receita YTD =
TOTALYTD (
    [Receita],
    'Calendario'[Data]
)

Num gráfico de linha por mês, mostra a curva do ano.

02

Receita MTD

Acumulado do mês até o dia selecionado.

02-receita-mtd.dax
Receita MTD =
TOTALMTD (
    [Receita],
    'Calendario'[Data]
)

Boa para acompanhar a meta mensal antes do mês fechar.

03

Receita AA

O mesmo período, um ano antes. Base de toda comparação anual.

03-receita-aa.dax
Receita AA =
CALCULATE (
    [Receita],
    SAMEPERIODLASTYEAR ( 'Calendario'[Data] )
)
04

Var % AA

Quanto a receita cresceu ou caiu contra o ano anterior.

04-var-aa.dax
Var % AA =
DIVIDE (
    [Receita] - [Receita AA],
    [Receita AA]
)

Formate como porcentagem. Sem ano anterior, DIVIDE devolve vazio em vez de erro.

05

Receita YTD AA

O acumulado do ano passado até a mesma data. Ao lado da Receita YTD, mostra se o ano está melhor.

05-receita-ytd-aa.dax
Receita YTD AA =
CALCULATE (
    [Receita YTD],
    SAMEPERIODLASTYEAR ( 'Calendario'[Data] )
)
06

Receita do mês anterior

O mês imediatamente antes do selecionado.

06-mes-anterior.dax
Receita Mês Anterior =
CALCULATE (
    [Receita],
    DATEADD ( 'Calendario'[Data], -1, MONTH )
)

Troque MONTH por QUARTER para comparar com o trimestre anterior.

07

Receita dos últimos 12 meses

Soma dos 12 meses até a data selecionada. Tira o efeito da sazonalidade.

07-receita-12m.dax
Receita 12M =
CALCULATE (
    [Receita],
    DATESINPERIOD (
        'Calendario'[Data],
        MAX ( 'Calendario'[Data] ),
        -12,
        MONTH
    )
)
08

Margem bruta %

Quanto sobra da receita depois do custo.

08-margem-bruta.dax
Margem Bruta % =
DIVIDE (
    [Receita] - [Custo],
    [Receita]
)

7/8
09

Desvio % do orçado

Quanto o realizado ficou acima ou abaixo do orçamento.

09-desvio-orcado.dax
Desvio % Orçado =
DIVIDE (
    [Receita] - [Orçado],
    [Orçado]
)

Orçamento costuma vir por mês. Guarde a data no primeiro dia do mês para relacionar com a Calendario.

10

Participação %

O peso de cada categoria no total do que está filtrado.

10-participacao.dax
Participação % =
DIVIDE (
    [Receita],
    CALCULATE (
        [Receita],
        ALLSELECTED ( Produto[Categoria] )
    )
)

ALLSELECTED respeita os filtros da página. Com ALL, compara com o total geral.
