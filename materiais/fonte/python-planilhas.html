01

Ler uma aba específica

Substitui abrir o arquivo e copiar a aba na mão. skiprows pula o cabeçalho do relatório.

01.py
import pandas as pd

df = pd.read_excel("arquivo.xlsx",
    sheet_name="Vendas", skiprows=2)

Para CSV com ponto e vírgula: pd.read_csv("a.csv", sep=";", decimal=",").

02

Juntar todos os Excel de uma pasta

Os 12 relatórios do ano viram uma tabela só, com uma coluna dizendo de qual arquivo veio cada linha.

02.py
from pathlib import Path

arquivos = sorted(Path("relatorios").glob("*.xlsx"))
vendas = pd.concat(
    [pd.read_excel(a).assign(Arquivo=a.name)
     for a in arquivos],
    ignore_index=True)

Todos os arquivos precisam ter as mesmas colunas.

03

PROCV sem PROCV

Traz o nome do cliente para a tabela de vendas. how="left" mantém todas as vendas, mesmo sem cadastro.

03.py
clientes = pd.read_excel("clientes.xlsx")
vendas = vendas.merge(
    clientes[["CodCliente", "Nome"]],
    on="CodCliente", how="left")

Vendas sem cadastro ficam com Nome vazio: vendas["Nome"].isna() mostra quais são.

04

Comparar duas planilhas

O que está só em A, o que está só em B e o que está nas duas. A coluna _merge diz de onde veio cada linha.

04.py
comp = a.merge(b, on="Pedido", how="outer",
               indicator=True)
so_em_a = comp[comp["_merge"] == "left_only"]
so_em_b = comp[comp["_merge"] == "right_only"]

Chave duplicada multiplica linhas. Use validate="one_to_one" para o pandas avisar.

05

Remover duplicados

Fica uma linha por CPF. keep="last" mantém a última ocorrência, a mais recente se a planilha estiver em ordem de data.

05.py
cadastro = cadastro.drop_duplicates(
    subset="CPF", keep="last")
06

Tabela dinâmica

Vendedor nas linhas, mês nas colunas e o total no fim, igual à tabela dinâmica do Excel.

06.py
tabela = pd.pivot_table(
    vendas, index="Vendedor", columns="Mes",
    values="Valor", aggfunc="sum", fill_value=0,
    margins=True, margins_name="Total")

07

SOMASES em uma linha

Total por região e produto, pronto para virar gráfico ou ir para outra planilha.

07.py
resumo = (vendas
    .groupby(["Regiao", "Produto"], as_index=False)
    ["Valor"].sum())

Troque sum() por mean(), count() ou max().

08

Limpar texto, valor e data

Nome sem espaço sobrando, "1.234,56" virando número e data no formato brasileiro.

08.py
df["Nome"] = df["Nome"].str.strip().str.title()
df["Valor"] = pd.to_numeric(df["Valor"]
    .str.replace(".", "", regex=False)
    .str.replace(",", ".", regex=False))
df["Data"] = pd.to_datetime(df["Data"],
    format="%d/%m/%Y")

09

Uma planilha por vendedor

Separa o arquivo geral em um arquivo para cada vendedor. Acaba com o filtrar, copiar e salvar como.

09.py
Path("saida").mkdir(exist_ok=True)
for vendedor, grupo in vendas.groupby("Vendedor"):
    grupo.to_excel(f"saida/{vendedor}.xlsx",
                   index=False)

Várias abas em um arquivo

O relatório final com uma aba para cada tabela.

10.py
abas = {"Vendas": vendas, "Resumo": resumo,
        "Por vendedor": tabela}
with pd.ExcelWriter("relatorio.xlsx") as arq:
    for nome, dados in abas.items():
        dados.to_excel(arq, sheet_name=nome)
