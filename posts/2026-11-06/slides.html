MEDIDA 1

Acumulado no ano (YTD)

Mostra quanto a empresa já faturou de janeiro até o mês selecionado.

Receita YTD =
TOTALYTD (
    [Receita],
    'Calendario'[Data]
)

[Receita] é a sua medida de soma, por exemplo SUM ( Vendas[Valor] ).

MEDIDA 2

Comparação com o ano anterior

Receita AA =
CALCULATE (
    [Receita],
    SAMEPERIODLASTYEAR (
        'Calendario'[Data]
    )
)

Var % AA =
DIVIDE (
    [Receita] - [Receita AA],
    [Receita AA]
)

Formate Var % AA como porcentagem e use cor verde e vermelha no visual.

MEDIDA 3

Desvio do orçamento

Mostra em porcentagem quanto o realizado ficou acima ou abaixo do orçado.

Desvio % =
DIVIDE (
    [Realizado] - [Orçado],
    [Orçado]
)

Use DIVIDE em vez de "/": ele evita erro quando o orçado é zero.
