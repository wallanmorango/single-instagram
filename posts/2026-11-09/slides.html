O que mudou

6 ajustes, zero regra alterada

  1. Filtrar o período na primeira leiturae não no fim da query
  2. Ler cada tabela uma vez sóem tabelas temporárias (#temp): no SQL Server, a CTE é recalculada a cada uso
  3. DATEFROMPARTS no lugar de FORMATo mesmo primeiro dia do mês, com muito menos custo
  4. Função de janela no lugar de auto-junção
  5. Uma agregação no lugar de duasseparando os meses com CASE
  6. Relacionamentos no modelono lugar das mesclagens do Power Query

Na prática

Antes e depois, no SQL

exemplo-ficticio.sql
-- exemplo com nomes fictícios
-- 1 leitura só, já filtrada
SELECT ClienteID, Data, Valor
INTO #pedidos
FROM Pedidos
WHERE Data >= @Inicio;

-- antes: FORMAT(Data, 'yyyy-MM-01')
DATEFROMPARTS(YEAR(Data), MONTH(Data), 1)

-- antes: a tabela juntada com ela mesma
MAX(Data) OVER (PARTITION BY ClienteID)

Para medir cada etapa: SET STATISTICS TIME, IO ON no SSMS. Ele mostra onde o tempo vai e se a query está calculando ou só esperando.
